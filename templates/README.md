# Templates

- `task-yaml/` — `task.yaml` starters, one per runtime. Copy one into a task folder made with `ignitify task:create <slug> --lang <runtime> --local`, then set `slug` to the folder name and run `ignitify task:validate <slug>`.
- The support report template is part of the troubleshooting skill: [`skills/ignitify-troubleshooting/support-report.md`](../skills/ignitify-troubleshooting/support-report.md).
